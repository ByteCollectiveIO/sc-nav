## At a glance

| | |
|---|---|
| **Who** | Every member. Reading is the main use; anyone can write. |
| **What** | The org's reports, how-to procedures, place and org dossiers, questions, and activity stats. |
| **Where** | Launcher group Run the Org, route `#/intel`. No watcher needed. |
| **When** | Before you head out, after something happens worth telling the org, and when you're stuck. |
| **Why** | What one member learns stays findable for everyone, instead of scrolling away in chat. |

## The basics

Org Intel has two halves. Switch between them with INTELLIGENCE and ACTIVITY at the top.

INTELLIGENCE is what the org knows. Its tabs:

- Feed (`#/intel/feed`): what's new. Reports, questions and debriefs, plus procedures, tactics and dossiers when they're published or revised.
- Library (`#/intel/library`): the org's procedures and tactics, grouped by activity.
- Dossiers (`#/intel/dossiers`): one page per place or per other org.
- Questions (`#/intel/rfi`): questions for the org and their answers.
- Review: only shows for reviewers, if your org checks entries before they go live.

The search box at the top searches all of it. **New** opens a menu of every kind you can write, and **Writing guide** at the end of the tab row explains each one.

ACTIVITY is the org's stats, built from what members do in the other apps. Nothing there is editable.

A report is something you saw, right now. It stays valid for a set time (6 hours unless you change it), then drops off the Feed. A procedure is how the org does a job. It stays useful for months and shows the game patch it was written for.

## Read the Feed

Use this at the start of a session to see what's happened.

1. Open `#/intel`. A first visit lands on the Feed.
2. Read the line that says how many entries are new since you last looked.
3. Use the filter chips (Reports, Procedures, Questions and others) to narrow the list.
4. Pick a system or activity from the drop-downs to see only what applies to you.
5. Click an entry to open it.
6. On a report you can confirm, click **Corroborate**. If it looks wrong, click **Dispute**.

Tick Show expired to see reports that have run out.

## Find a procedure in the Library

Use this when you want to know how your org does a job, like an escort or a mining run.

1. Click **Library**.
2. Pick an activity, or type what you need into the search box at the top.
3. Open an entry. Doctrine entries, the org's official way, are listed first.
4. Check the patch it was written for. If the game has moved on, the entry says so.
5. Click **Watch** if you want the Feed to tell you when it changes.

If an event lists required reading, open each entry and click **I've read it**.

## Ask the org a question

Use this when you can't find the answer in the Library.

1. Click **New**, then **Question**.
2. Write the question as the title.
3. Add what you already know and what would help.
4. Click **Post question**.
5. When an answer solves it, open the question and click **Accept this answer**.

To ask about a place, open its dossier and click **Ask about it**.

## File a report

Use this when you see something the org should know about, like a gate camp.

1. Click **New**, then **Report**.
2. Fill in the SALUTE block: Size, Activity, Location, Unit, Time, Equipment. Location and time are required. **Now** fills in the time.
3. Check how long it stays valid.
4. Write what happened and what others should do about it.
5. Leave **Announce in Discord** ticked to post it to the org's channel, or untick it to keep it in the app.
6. Click **Publish report**.

You can fix typos for 15 minutes. After that, click **Add update** on the report instead. From the Danger Board, **Write up →** on a warning starts a report already filled in.

## See the activity stats

Use this to see what the org has been doing and who's contributing.

1. Click **ACTIVITY** at the top.
2. Start on Overview for the headline numbers.
3. Move between Mapping, Hauling, Trading, Surveying, Market and Leaderboards with the tab strip, or the left and right arrow keys.
4. Use the All-time and This week toggle where a section has one.

## Tips

- Describe ships, orgs and behaviour, not individual players. Members can flag entries that name a player.
- Your drafts save as you type and only you can see them. They're listed at the top of the Library.
- Every app has a guide like this one. Click the app-guide tag on any of them to see the full set, or open the New member guides collection.
